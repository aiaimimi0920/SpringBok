# 把接入任务交给 AI

在自己的服务仓库中，将下面的任务交给 AI，并提供 SpringBok 的 [AI 文档入口](https://github.com/aiaimimi0920/SpringBok/blob/main/ai-docs/README.md)。

```text
阅读 SpringBok 的 ai-docs/README.md 及其引用文档。
先调查当前服务的构建、部署、数据迁移和业务验证方式。
按现有 SBA 合同实现 .sba 接入，不更换业务栈，不编造额外协议文件。
使用当前源码校验器验证，明确已实现动作、测试结果和未验证项目。
未经具体批准，不创建或删除云资源，不发布服务，不处理真实凭据。
```

## 为什么有两个入口

ai-docs 面向执行任务的 AI，强调约束、文件定义与验收边界；本站面向开发者，提供导航、阅读顺序和代码排版。逐文件参考与接入流程由相同 Markdown 源构建，不维护第二套字段解释。

现有 docs 目录保留内部设计与阶段历史，不全部公开打包成本站内容。开发计划不是协议字段的事实来源；协议事实最终以当前校验器和测试为准。
