# UI-05 正式管理界面文案盘点

日期：2026-10-07。范围：`public/cloud-admin/` 四页及其动态渲染模块、隐藏面板和 CSS。
历史 demo/test-console 不属于线上控制面，不改它们的历史证据。负责人：主 AI。

| 区域 | 删除或精简 | 保留 |
| --- | --- | --- |
| 云资源 | 删除读取完成后的整句指路说明与空通知条；移除空态教程、Workers 自证说明 | 账户/资源数据、只读标记、分页、权限错误、添加中/失败 |
| 连接设置 | 删除权限填写教程、加密原理、部署流程说明、停用解释；按品牌显示凭据标签 | 连接目标、只读验证状态、停用确认、失败反馈 |
| 新建部署 | 删除信任代码教程、声明文件要求、首次部署流程解释、资源登记教程、CSS 空表单指引；精简完成通知 | 首次部署标题、精确 SHA、公开配置勿填密钥约束、确认时实际修改云资源的后果、unknown 状态 |
| 历史部署 | 删除固定联调背景说明、元数据目录教程、服务器加入原理、任务读取与 SBA 解释 | 固定测试标签、任务/回执、测试执行确认、加入材料密钥警示 |
| 目录/服务器加入 | 删除状态中的括号解释、目录更新自证、常驻步骤教程 | 登记/归档/加入状态、版本、期限、错误与不确定恢复约束 |
| 心跳/遥测 | 删除采样原理、不是零/不证明健康等重复解释、陈旧阈值教程 | 指标 scope、单位、时间、已过滤计数、未知/未上报/陈旧状态、实际错误 |

不是只隐藏文本：删除说明节点与控制器引用；资源成功通知清空，并移除其空容器占位。
不修改后台请求、权限、幂等、任务执行或数值计算；不以页面精简扩大已验证范围。

验收：静态文案防回归、四页视觉检查、资源空通知不可见、品牌字段与错误反馈、
原连接/部署/目录/加入/心跳/遥测行为测试。证据与发布回执位于
`linshi/springbok-ui-05-20261007/`；真实用户业务验收与合成浏览器检查分开记录。
