# 发布记录查询

控制台把已验证快照中的请求与准备、执行事件按精确请求ID关联。每页最多10条，
可筛选四个固定服务，展开目标资源、不可变镜像、Update ID及关联事件序号。
操作只读取浏览器已有快照，刷新仅调用既有GET状态接口；不会写日志、读取Komodo、
提交执行、恢复未知请求或授予权限。

准备独有记录优先展示，仍显示未知；执行请求按起始执行序号倒序。两本日志各有
自己的revision，不能按数字混排成时间线。详情同样分别列出准备和执行事件。
已取得回执只显示待核对，成功、失败和已撤销来自现有投影。重复ID、跨服务或
不一致的计划拒绝关联；缺失执行起始或投影不能推断成功。

筛选切换和刷新回第一页并关闭旧详情。审计索引按日志类型独立分页，只展示已有
序号、事件类型和关联ID，不展开actor、配置、错误对象等额外字段；持久原始日志
保持原样。索引不受服务筛选影响，保留重启等全局事件。

本轮验证纯函数排序、分页边界、空集合、歧义ID、缺失历史、未知状态及字段白名单，
以及真实Chrome假后端的筛选/分页/刷新/详情/390px布局和无后台写入。
未授权或运行新的真实容器测试。M10证书原样保存，CI读取固定历史提交验证22个
摘要；当前变更在combined-console-evolution.json明确排除该历史运行覆盖。
