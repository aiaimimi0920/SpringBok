# 本地配置检查页面

Node.js 22+，运行 `node scripts/config-ui.mjs`，手动打开终端给出的
http://127.0.0.1:3211 。不会自动打开浏览器，不需要Docker或登录。

选择UTF-8 JSON文件（上限64KiB），格式沿用[用户服务配置](user-configuration.md)。
可以先选择examples/config/services.json理解结构，其镜像和Server ID都是占位符。
浏览器只将文件内容发送到当前loopback服务；服务端直接调用同一compileConfiguration，
不会另外维护一套前端校验规则，不记录文件名、原文、密钥或访问日志，不落盘。

可选基线文件会启用[发布差异预览](config-change-review.md)，两份输入均调用同一编译器；不提供基线时保持单份候选校验。

页面显示规范后的项目、manifest摘要、已配置/遗漏服务，以及每个环境的目标、端口、
命名卷、未解析密钥引用和待核对项。不要填写真实密钥。通过只代表符合输入规则，
不代表镜像可用、权限具备、资源已导入或部署成功。结果仍为readiness/executable=false。

仅点击“下载校验草稿”才会触发浏览器下载springbok-review.json，其内容与CLI结果
一致。下载由浏览器管理；服务端不保存。选择新文件、取消选择、清空、页面返回或
离开会撤销旧结果和下载资格；无效输入不能继续导出旧的有效草稿。过期响应被丢弃，
重复选择不会叠加旧卡片。关闭进程也清除内存会话token。

## HTTP边界

只绑定127.0.0.1，精确校验Host及端口；拒绝外部Origin和跨站Fetch Metadata。
POST必须来自同源、使用JSON和当前内存CSRF token。无CORS开放，无任意URL或文件
路径接口；静态路径固定。单份校验Content-Length与实际流字节均限制64KiB；比较请求最多128KiB+32字节，且两个manifest分别不超过64KiB。上传均有5秒截止。
CSP不允许外部脚本、网络或嵌入，响应no-store。token只防跨站请求，不是本机恶意
进程防护、用户身份认证或生产登录，不应公开监听或通过反向代理暴露此页面。

## 验证范围

真实本地HTTP测试检查共享编译结果、Host/Origin/CSRF/方法/路径、过量或缓慢上传、
非法UTF-8、错误不回显敏感内容。普通Chrome测试检查明确下载、替换无效文件撤销旧
导出、取消事件、键盘清空、过期响应、Back/Forward、重复选择、390px布局及请求仅
到本机固定路径。没有新增真实Komodo执行、凭据配置或服务器接入。原有M10运行文件
与证书均未修改；当前功能不继承历史运行的生产就绪声明。
