# SV-07-S02：Gmail 管理员初始化

云资源的“添加资源”支持 Gmail 管理员资料：邮箱和默认管理员密码。这里只登记应用登录资料，
不申请 Google OAuth、不读取邮箱，也不把邮箱标为已验证。密码至少12字符且包含大小写、数字、
符号，UTF-8最多72字节；真实默认值只保存在 owner 隔离的 AES-GCM vault，不在代码中预置。

支持初始化的自动部署声明可添加 `administrator: {emailPath, secret}`。
部署表单选择管理员邮箱（只有一个时默认选中），默认使用保存的密码；选择“本次密码”可覆盖。
预览只显示邮箱和密码来源，不显示值。返回修改可明确切回默认密码。

临时覆盖有效15分钟，创建新资料时回收已过期覆盖；被确认任务另有私有密文副本，不受临时
引用过期影响。签名计划只有不可猜测引用和公开邮箱；一次性 OIDC permit 向固定SHA应用传秘密。
列表、配置、GitHub dispatch、日志、回执均不得带密码或密码摘要。更新及预升级只传不适用标记，
不解密原管理员密码，不重设账号或授予旧账号权限。

NAccount仅首次 deploy 在迁移后、Worker发布前创建用户，并按真实 super_admin 角色赋权。
规范化同邮箱（含软删除）已存在时拒绝，不覆盖密码。emailVerified和MFA验证状态仍为初始值。
用户创建和赋权是两次D1 REST写入，不声称事务：部分写入或回执不确定会停止为unknown，禁止自动重试。
实际管理员登录、邮件和MFA必须单独验收；初始化读回成功不是登录验收。
