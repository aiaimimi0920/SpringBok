# SV-04：声明驱动自动新建

负责人：主 AI。当前子任务 `SV-04-S01` 为平台自动创建、账户隔离、界面与合成验收。
不执行新的生产应用部署；NAccount 适配、精确 GitHub 来源和控制面发布分别记录，
不能把本页的平台支持当作 NAccount 已实现零填写。

## 声明与兼容

`.sba/deployment.json` 的 `schemaVersion: 1` 继续读取并使用已有资源；manifest
版本独立，不随部署声明版本自动改变。v2 增量字段：

- `accountMode` 为 `single` 或 `multiple`；`accounts` 首项是 `runtime`，其 `path`
  必须等于 `accountPath`。每项包含 `key/label/path/secret`，secret 名称必须唯一，
  且集合与应用 manifest 的 secrets 相同。
- 每个配置 field 增加 `template`，为 null 时读取 defaults；文本模板只接受
  `{instance}` 和 `{subdomain:accountKey}`。subdomain 从该账户官方只读接口取得。
- 每个 resource 增加 `account/nativeAccount/nameTemplate`。名称含 `{instance}`，
  不接受用户输入远端 ID。`nativeAccount` 非 null 时强制同账户，不能以多账户
  声明假装 Cloudflare 原生绑定支持跨账户。null 代表应用适配自行使用相应账户凭据，
  并不提供网络代理，也不认证任意应用代码的正确性。
- 每个 target 增加 `account`；Worker、资源的占用以对应账户分别保护。

单账户只选择一个已验证连接；多账户按声明的账户槽选择来源。实例名自动生成且
可修改，资源清单只读。预览仍固定源码 SHA、账户 revision 和配置，明确确认后才创建。
新建 v2 不要求填写配置字段，因此声明必须提供应用实际可用的默认值；不能填写虚假
域名、邮箱或 ID 以绕过应用校验。平台与版本仍显示，旧 v1 表单和导入入口保持兼容。

## 写入、重入和更新

1. 审阅批准绑定预览摘要；服务端重读源码与连接后逐字比较计划。
2. Vault 原子保存准备意图和资源容量预留，再按排序后的账户列表取得各自占用。
   后续账户冲突时不创建任何资源；已持有的占用保留，不能用新任务绕过。
3. 每个 POST 前持久保存 `creating`，调用 Cloudflare D1/KV/R2 固定创建端点，
   不重试、不跟随重定向，限制超时和响应大小，校验返回名称与 ID。
4. 每次确定成功立即保存结果；全部完成后原子登记资源，生成最终公开配置。
   名称和返回 ID 均绑定到账户占用，之后才初始化任务和派发 GitHub 执行器。
5. 重复提交只读取状态；崩溃、响应未知或部分成功不再次取得创建权。
   已知创建资源仍保留在准备记录中；不得自动删除、回滚或重新创建。
6. Runner 一次性许可只取得 manifest 明确声明的来源凭据，未使用连接不传递。
   沿用已批准 in-flight 任务的既有凭据语义，后续停用连接不是取消该任务的回执。
7. 更新从前一可信任务继承配置与资源，验证身份/目标/配置不变，不再创建资源。
   原 v1、导入记录和原 NAccount unknown 回执不被重写。

扩展复用原 SQLite Durable Object 表，不清空或迁移历史数据。旧版控制器回退时
仍可看到索引和占用，新 v2 声明不受旧版支持；不能用回退作为准备未知任务的恢复方法。
资源容量预留在 unknown 时保留，人工处置协议不属于本子任务。

## 验证与未完成项

本地覆盖自动 D1/KV/R2、来源隔离、第二账户占用冲突、生成 ID 持久占用、容量不足
零写入、部分成功及重启不重放、subdomain 默认、旧部署/导入和更新兼容；浏览器验证
单账户零资源选择、窄屏、真实 workerd 提交与更新不重建。多账户用量按来源连接读取，
不会把同名 R2 或 Worker 的不同账户统计混在一起。

证据：`linshi/springbok-sv-04-20261008/`。精确检查数、Git SHA、PR 与发布以独立回执
为准。所有新建供应商与 Access 身份均为合成测试，不等于真实生产创建或用户验收。

NAccount 仍有自定义域名、同账户跨 Worker 访问和已验证邮件发信配置约束；尚未改成
v2，也没有静默关闭邮件功能。已有真实 NAccount 导入由 SV-03 完成，本项不重做。
导入仍核验单个账户；多账户 v2 声明暂不允许通过单账户导入路径登记，避免猜测归属。
