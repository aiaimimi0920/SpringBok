1. 应用版本

仅部署你信任的代码。应用连接读取源码；执行器由平台固定，不接受任意工作流。仓库需包含 .sba/manifest.json 和 .sba/deployment.json。

2. 运行目标与资源

Cloudflare Workers · 首次部署。已有实例不要重新执行首次部署；更新需独立升级流程。

只绑定已登记资源，不自动创建 D1、KV 或 R2。读取超过 5 分钟或连接变更后，请到云资源页重新读取并登记。

3. 应用公开配置

配置随公开任务传给 GitHub Actions；不要填写密钥、密码或 Token。Cloudflare API Token 由服务端在一次性许可中单独交付。

4. 审阅与确认

此版本只生成计划，执行入口尚未启用。
